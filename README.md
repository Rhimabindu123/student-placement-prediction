# student-placement-prediction
# Student Placement Prediction Using Machine Learning

## 📌 Project Overview

This project uses Machine Learning to predict student placement outcomes based on academic performance and other student-related features.

The project demonstrates a basic machine learning workflow using Python, Pandas, and Scikit-learn.

## 🎯 Objectives

- Understand the basic workflow of a machine learning project.
- Prepare student data for model training.
- Train a Decision Tree Classifier.
- Evaluate model performance using accuracy.
- Predict placement outcomes for a new student profile.

## 🛠️ Technologies Used

- Python
- Pandas
- Scikit-learn
- Google Colab
- Jupyter Notebook

## 📊 Dataset Description

The project uses a manually created dataset containing 30 student records.

The features include:

- CGPA
- Technical skills
- Projects
- Internships
- Certifications
- DSA score

The target variable represents the student's placement outcome.

**Note:** This is a small, simulated dataset created for learning purposes. It does not represent real-world placement data.

## ⚙️ Machine Learning Algorithm

### Decision Tree Classifier

A Decision Tree Classifier is used to learn patterns from the training data and predict whether a student will be placed.

The dataset is divided into training and testing sets to evaluate the model.

## 📈 Model Evaluation

The notebook reports a test accuracy of 83.33%.

However, the test set contains only six student records. Therefore, this result is preliminary and should not be considered evidence of reliable real-world placement prediction.

1. Download or clone this repository.
